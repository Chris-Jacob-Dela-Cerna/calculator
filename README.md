# Calculator

A basic arithmetic calculator with a running history, built from scratch with vanilla HTML, CSS, and JavaScript.

🔗 **[Live Site](https://chris-jacob-dela-cerna.github.io/calculator/)**

---

## What I built

A calculator that handles basic arithmetic, keeps a running history of previous calculations you can click back into, and supports full keyboard input alongside the on-screen keypad. Design is inspired by the Ubuntu GNOME Calculator app — clean lines, minimal construct.

---

## What I was learning

- Structuring calculator logic (operator precedence, chained operations, decimal handling)
- Building a running history log and making past entries re-usable as new input
- Wiring up both keyboard events and click events to drive the same underlying logic
- Styling a focused, minimal UI modeled after an existing design system

---

## What's the point?

It's not a scientific calculator and doesn't aim to be. The focus was clean state management between input, history, and display, plus matching a real-world UI reference closely.
